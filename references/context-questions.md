# 针对性上下文与提问预算

## 三层上下文

- 稳定画像：长期角色、常见资源、稳定偏好、硬边界；只有用户确认后才复用。
- 领域画像：学习基础/材料，或居住条件/家庭成员/空间等。
- 本次上下文：当前目标、临时限制、截止时间、正在纠结的步骤。
- 未知项：未提供且不能可靠推断的信息；拒答也是合法状态。

## 问题生成顺序

完成原帖拆解后，对每个候选问题问一句：“答案会不会改变保留/改造/暂缓/放弃，或改变时间、资源、验证分支？”不会就不问。

按决策影响启发式排序，不计算概率：

1. 安全与硬边界；
2. 本次唯一目标；
3. 可用时间、预算、场地和设备等硬约束；
4. 当前基础与过去尝试；
5. 会改变验证设计的执行环境。

## 数量与会话协议

- 首轮 1–5 题，成组提出，每题附一句“为什么需要”；
- 只有回答开启新的关键分支才追问，最多一轮、最多 3 题；
- 全过程最多 8 题；不得通过把多个独立问题塞进一个编号来规避；
- 每个问题记录 `round`、`question`、`why_it_matters`、`judgments_it_can_flip`、`uncertainty`、`priority`、`answer_status`；
- 用户可回答“不知道/不想说”，随后标 `declined` 或 `unknown`，进入条件式试穿；
- 已有原帖或已确认画像答案的问题不重复问；画像冲突时先展示两条事实，让用户选择本次适用项，不自动覆盖。

## 好问题与坏问题

好：“工作日能稳定留出多少分钟？这决定新词量和每日阶段。”
坏：“你的自律能力怎么样？”

好：“是否允许打孔或固定家具？这决定收纳步骤是否保留。”
坏：“请完整介绍你的家庭情况。”

## 提问后检查

交付前统计真实问题数和分支数：首轮≤5、追问≤3、总数≤8、分支≤3。超出时删去不会改变决定的问题，不把预算用来满足问卷完整性。
