# 能力降级矩阵

| 缺失能力 | 必须保留的核心路径 | 降级与诚实声明 |
|---|---|---|
| Python/脚本不可用 | 拆→对→改→试→存；三件产物 | 按卡片末尾清单人工检查；说明“未运行自动校验” |
| 本地不可写 | 本次交付与可选画像候选 | 仅存会话内；输出可复制档案卡；说明未持久化 |
| 不能跨会话 | 本次完整交付 | 用户下次手动带回档案卡，不假装记得 |
| 不能多轮 | 提问环节以一次性关键条件清单替代 | 允许拒答；按未知输出假设和至多3条分支 |
| 上下文短 | 一次一篇经验 | 单次处理 ≤1,500 字或 ≤12 步；超出按步骤边界切分并标注“第 n/m 段（原帖第 x–y 步）”，标记截断边界 |
| 无图片能力 | 文本卡 | 交付 Markdown/纯文本，用户自行截图 |
| 无网络 | 全流程 | 不抓链接；外部断言保留“作者声称/未知” |
| 模型排队/质量波动 | 不伪造实时输出 | 可展示预生成卡片，明确“已生成示例” |

正式运行环境是支持加载 Skill 的 Agent。普通网页聊天若不能加载本 Skill，不属于正式支持范围；首版不附带另行维护的 portable prompt。

无脚本、无持久化人工通过条件：用户正文经过拆解和至少一轮提问；拒答走条件式；三件产物齐；个人版含时间预算、资源、检查点、兜底和第一个动作；按需验证卡齐；未声称已运行脚本或已跨会话保存。
