# 方法：拆、对、改、试、存

## 一、经验最小单位

一次只处理一篇经验帖。目标不同但步骤共用时，先让用户确定本次唯一主目标；其余目标列为“不处理”，不要混成大杂烩。

## 二、拆解记录

按原文提取：

- `author_goal`：作者想完成什么；
- `author_conditions`：只收明示事实，未知不补；
- `steps`：可执行动作，保留原顺序和编号；
- `claims`：作者声称的结果，前加“作者声称”；
- `hidden_assumptions`：步骤成立所需但原文未明说的条件，标为推测；
- `content_type`：可执行经验、作者观点、事实断言、营销话术、高风险或无可执行步骤；
- `evidence_strength`：仅描述原帖有没有记录、样本和对照，不替它评级为科学结论。

原帖没有动机、因果、用户条件时，不自行创造。对“速记、速读、右脑开发”等宣传保持谨慎，只把具体动作带入试穿。

内核可迁移不等于原步骤保留；迁移的是拆→对→改→试→存流程，不是把每条原步骤照搬。

## 三、逐条对齐与判定

每个 `step` 都进入且只进入一个状态：

| 状态 | 判定条件 | 必须回答 |
|---|---|---|
| 合身·保留 | 当前条件支持尝试 | 哪些已知条件支持？ |
| 需改·改造 | 目标一致，执行方式冲突 | 动作具体改成什么？ |
| 暂缓 | 成本、依赖或风险当前不合适 | 何时、满足什么条件再评估？ |
| 退回·放弃 | 与个人目标或硬边界冲突 | 冲突是什么？ |

每条留痕字段：`step`、`personal_conditions`、`status`、`reason`、`evidence`、`source`、`background`、`options`、`decision`、`consequences`、`reversibility`。来源用“原作者 / 个人改造 / 实践验证 / 仍属推测”，其中“实践验证”只能来自用户真实反馈。

禁止适配总分、百分比、信息增益分数。百分比可用于正确率等可观察指标，不得转成“适合度”。

## 四、条件式试穿

任何关键未知会翻转判定或方案时：

1. 明示未知，不写成确定事实；
2. 最多给两条主分支和一条兜底；
3. 每条写“如果…那么…”，并说明分支对应的原步骤；
4. 个人 v1 标为“条件式 v1”，只含各分支当前可执行的部分；
5. 以最小实验或下一次补充信息消除未知，不假装已经选定分支。

## 五、风险门控（三级响应）

判定单位是**动作**，不是品类；逐步骤判，不逐帖判。

| 级别 | 触发（按动作） | 处理 | 是否交付 |
|---|---|---|---|
| **退出 Exit** | 不可逆、需法定资质、涉他人安全：诊断/处方/停药、法律意见、投资买卖、心理危机干预、手术与医美操作、结构改造/电气/燃气/消防、儿童·老人·宠物安全操作、大额不可逆消费、其他危险行为 | 停止个性化建议、不生成执行方案或验证卡；仍输出拆解、为什么退出、应找哪类专业人员与一般性安全常识 | 是（轻量退出格式） |
| **谨慎 Cautious** | 可逆但有身体/金钱/隐私代价：限制性饮食与体重管理、保健品/补充剂、非操作类护肤、运动强度、睡眠干预、情绪调节方法、小额消费、涉及他人信息 | 正常做，但必须：①顶部 3 行风险提示；②动作取保守值，**不沿用原帖剂量**、克数、卡路里或强度；③列禁止项（不替代治疗、不极端限制、不给药物剂量）；④不承诺结果；⑤验证卡停止条件含“出现 X 症状即停”；⑥建议同步咨询专业人员 | 是（三件产物＋风险区） |
| **常规 Standard** | 无上述特征 | 现有流程不变 | 是 |

判定规则：

1. 逐步骤判，不逐帖判。整帖退出只在“全部步骤命中 Exit”或“帖子核心就是 Exit 级动作”时发生。
2. 同一帖可混合：常规步骤正常改，谨慎步骤判“暂缓”并给保守替代，Exit 步骤单独标为“退出某步骤”并说明不执行。
3. 拿不准时降一级（Cautious），不升到 Exit。

Cautious 下的“暂缓”指暂缓原剂量、改给保守替代，不新增第五档判定。

## 六、版本与诚实状态

- `v0`：作者原经验；`v1`：本次个人改版；`v2`：真实实践反馈后的增强更新。
- 可选状态：草稿、待验证、部分验证、对当前用户有效、已退役、未执行、证据不足。
- 没执行不能写无效；一次体验不能写长期有效；作者有效不能写对我有效。
- 分享和演示均不能把“计划做”改写成“已经做到”。
